# BMI Calculator Pro

Advanced BMI tracking application developed using Python and CustomTkinter.

## Features

- BMI Calculation
- Metric and Imperial Units
- Goal Weight Tracking
- Healthy Weight Range Suggestions
- BMI History Management
- Delete Records
- PDF Export
- BMI Trend Visualization
- Dark/Light Mode
- Modern GUI

## Technologies Used

- Python
- CustomTkinter
- Matplotlib
- CSV
- FPDF

## Installation

```bash
pip install -r requirements.txt
python bmi_calculator.py
