# Password Generator Pro

A modern password generation application built using Python and CustomTkinter.

## Features

- Secure Password Generation
- Password Length Slider
- Uppercase Letters
- Lowercase Letters
- Numbers
- Symbols
- Exclude Similar Characters
- Password Strength Analysis
- Copy to Clipboard
- Password History
- Delete Records
- PDF Export
- Dark/Light Mode
- Password Visibility Toggle

## Technologies Used

- Python
- CustomTkinter
- CSV
- FPDF

## Installation

```bash
pip install -r requirements.txt
python password_generator.py
```
