# Weather App Pro

A modern weather forecasting application built using Python and CustomTkinter.

## Features

- Real-Time Weather Data
- City Search
- Temperature Display
- Feels Like Temperature
- Humidity Information
- Wind Speed
- Weather Conditions
- Search History
- PDF Export
- Dark/Light Mode
- 5-Day Forecast

## Technologies Used

- Python
- CustomTkinter
- Requests
- CSV
- FPDF

## Installation

```bash
pip install -r requirements.txt
python weather_app.py
```
